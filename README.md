# Classe Orchestre

Application web temps reel pour faire jouer une classe entiere sur telephone.

## Demarrage

```bash
bun install
bun run dev
```

Le backend ecoute sur `http://localhost:3000` et le frontend Vite sur `http://localhost:5173`.

Variables backend utiles :

```bash
cp backend/.env.example backend/.env
```

Le mot de passe admin par defaut est `admin123`.
